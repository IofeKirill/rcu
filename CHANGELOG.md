# Журнал изменений

## [4.1.0] — 2026-10-14

- Добавлен раздел «Избранное»: команды можно добавлять и удалять через контекстное меню. Для E6, E7 и H сохраняются отдельные списки после перезапуска VS Code.
- Раздел «Избранное» выделен жёлтой звездой; рядом отображается количество команд или «Пока пусто».
- Кнопки выбора контроллера расположены в порядке E6 → E7 → H. При первом запуске выбран E6; последующий выбор запоминается.
- В информации о командах восстановлены цветные заголовки, выделение параметров и подсветка примеров Python. Подсветка работает без внешних скриптов и подключения к интернету.

## [4.0.0] — 2026-10-14. Глобальное обновление!

- Добавлена поддержка E7-RCU: общий набор команд E6-RCU и отдельный раздел «ИИ-камера» для E7-RCU. Выбор E6-RCU, E7-RCU и H-RCU меняет список команд, сохраняя написанный код.
- Добавлено подключение к контроллерам по Bluetooth: поиск, загрузка Python-файла, запуск кода из редактора, остановка программы, отключение и журнал работы. Поиск отображает состояние выполнения.
- Расширена работа по USB: загрузка на накопитель, запуск и остановка через COM-порт, отключение и журнал. Диск и последовательный интерфейс одного контроллера объединяются при подтверждённом сопоставлении Windows; улучшена обработка повторного подключения.
- Добавлены индикаторы состояния для конкретных устройств: красный — не подключено, жёлтый — идёт подключение, зелёный — подключено. Подключение Bluetooth отключает USB и снимает выбор накопителя; выбор или подключение USB отключает Bluetooth. Одновременно активно одно подключение.
- Добавлены команды NFC-меток, датчиков дождя и качества воздуха, матричного экрана (`display`), насоса и электромагнита (`actuator`), радиомодуля и радиопульта (`rf`), модуля IoT (`iot`). Для новых команд подготовлены русские описания параметров и примеры.
- Для ИИ-камеры (`aicam`) добавлены команды переключения режимов и чтения результатов, подробное руководство и семь примеров: проверка связи, лица, QR-коды, цвета, линия, координаты человека и движение по линии с ПД-регулятором.
- Добавлена автоматическая вставка импорта нужной библиотеки при выборе команды. Существующие импорты учитываются и не дублируются; новые файлы создаются только с `import rcu`. Обновлены подсказки библиотек Python.
- Настройка портов расширена до восьми моторных и восьми датчиковых портов. Поддерживаются вручную написанные назначения без комментариев; сохранение учитывает номер из кода и сохраняет пользовательские имена устройств.
- Обновлены учебные примеры: скорость и коэффициенты регуляторов читаются из ячеек памяти, показания световых датчиков нормируются, исправлено сохранение состояния ПИД и управление энкодером клешни. Добавлена функция `sgn` в команды управления.
- Упорядочены разделы команд; конструкции программирования объединены в разделе «Циклы, условия и функции».
- Упрощена системная панель: создание папки проекта удалено, операции подключения и загрузки доступны в соответствующих панелях USB и Bluetooth. F6 загружает файл через выбранный способ подключения.
- Исправлены ошибки открытия информации о командах, регистрации команд и работы интерфейса. Внесены мелкие правки описаний, комментариев и примеров; исправлены опечатки.
