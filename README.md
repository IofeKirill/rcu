# ZMROBO Python Russian (Not Official)

## Обзор

Расширение для Visual Studio Code помогает писать программы на Python для роботов ZMROBO: выбирать команды, читать русские описания и примеры, настраивать порты, загружать и запускать программы на контроллере.

**Это неофициальное расширение.** Разработчик не связан с компанией ZMROBO. Расширение создано для себя и других любителей робототехники и не используется в коммерческих целях.

Доступны наборы команд **E6-RCU, E7-RCU и H-RCU**. E7-RCU включает общий набор E6-RCU и дополнительный раздел ИИ-камеры. Возможности конкретного устройства зависят от модели, прошивки и подключённых модулей.

## Что нового в 4.0.0

- Подключение по Bluetooth: поиск, загрузка файла, Play, Stop и журнал.
- Запуск и остановка через USB COM-порт, улучшенное обнаружение и повторное подключение USB.
- Отдельные индикаторы состояния устройств и автоматическое переключение между USB и Bluetooth.
- Поддержка E7-RCU и ИИ-камеры с подробным руководством и семью примерами.
- Команды NFC, дождя, качества воздуха, матричного экрана, исполнительных устройств, радиомодуля и IoT.
- Автоматическое добавление нужных импортов и настройка восьми моторных и восьми датчиковых портов.
- Обновлённые учебные примеры, исправления ошибок и опечаток.

Полная история версий — в [CHANGELOG.md](CHANGELOG.md).

## Начало работы

1. Установите расширение из [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=IofeKirill.rcu-extension).
2. Создайте или откройте папку проекта средствами VS Code.
3. Откройте панель ZMROBO. В разделе «Команды для робота» выберите E6, E7 или H. Выбор меняет список команд; уже написанный код сохраняется.
4. В разделе «Системные команды» нажмите «Создать файл для проекта» и задайте имя программы. Файл создаётся с импортом `rcu` и функцией `task1()`.
5. При необходимости откройте «Настроить порты» и введите имена подключённых устройств.
6. Нажмите на нужную команду в дереве: она появится в редакторе, а импорт библиотеки добавится в начало файла, если его ещё нет.
7. Замените параметры команды значениями своей программы. Для перехода между полями вставленной команды используйте Tab.
8. Для загрузки сохраните Python-файл, найдите и выберите контроллер в панели USB или Bluetooth.

Чтобы открыть описание, нажмите правой кнопкой мыши на команду и выберите **«Информация о команде»**. В системной панели также доступны **«Примеры программ»**: пример открывается как новый несохранённый документ.

## Требования

- Visual Studio Code с установленным расширением ZMROBO.
- Рекомендуются расширения Microsoft Python и Pylance для работы с Python-кодом. Для наглядных отступов можно установить indent-rainbow.
- Для подключения по Bluetooth и отладки через USB COM-порт нужен **Python 3.10 или новее** на компьютере.
- Для Bluetooth нужна библиотека **bleak**, для USB COM-порта — **pyserial**. Их можно установить командами расширения или из терминала.

Для Windows:

```powershell
py -m pip install bleak pyserial
```

Для других систем, если Python вызывается как `python3`:

```bash
python3 -m pip install bleak pyserial
```

В настройках **ZMROBO → Bluetooth: Python Path** можно указать путь к исполняемому файлу Python. Этот параметр используется для обоих способов отладки. Если путь не задан, расширение вызывает `py` в Windows и `python3` в других системах.

Библиотеки `rcu`, `motor`, `sensor`, `aicam` и другие библиотеки робота выполняются на контроллере. Подсказки в VS Code помогают редактировать код; для проверки программы используйте робот.

## Команды и импорты

При добавлении команды расширение автоматически вставляет импорт её библиотеки с русским комментарием. Уже существующие импорты, в том числе объединённые и с псевдонимами, учитываются. Повторное добавление команды не создаёт ещё один импорт.

Новый файл содержит только основную библиотеку:

```python
import rcu  # Основная библиотека для управления роботом.

def task1():
    pass

task1()
```

Остальные библиотеки добавляются по мере использования команд. В дереве представлены моторы, колёсная база, сервоприводы, датчики, экран, управление, радиомодуль, IoT и другие возможности выбранного контроллера. Функция `sgn` доступна в разделе «Циклы, условия и функции».

## Настройка портов

В окне «Настроить порты» доступны **восемь портов моторов и восемь портов датчиков**. Имена устройств рекомендуется писать заглавными буквами, например `LEFT_MOTOR` и `LIGHT_SENSOR`. Расширение сохраняет введённый регистр и не переименовывает устройства автоматически.

Пример блока настроек:

```python
# ---------- Настройки моторов и датчиков ----------
LEFT_MOTOR = 1  # устройство подключено на порт Motor 1
RIGHT_MOTOR = 3  # устройство подключено на порт Motor 3
LEFT_LIGHT = 5  # устройство подключено на порт Sensor 5
RIGHT_LIGHT = 6  # устройство подключено на порт Sensor 6
# --------------------------------------------------
```

Настройка портов создаёт и обновляет имена в программе. Используйте эти имена в командах вместо номеров портов. Вручную написанные назначения внутри блока могут быть без комментариев; номер берётся из присвоенного значения. Если назначение нельзя однозначно определить, укажите тип порта комментарием `Motor`/`Sensor` или используйте имя устройства в соответствующей команде.

## Подключение и загрузка

В расширении есть отдельные панели **«Устройства USB»** и **«Bluetooth»**. Для каждого устройства показываются имя, адрес или порт и состояние:

| Цвет кружка | Состояние |
| --- | --- |
| Красный | Не подключено |
| Жёлтый | Выполняется подключение |
| Зелёный | Подключено; для отдельного USB-накопителя — выбран для загрузки |

Одновременно используется одно подключение. Подключение Bluetooth отключает USB-отладку и снимает выбор накопителя. Выбор или подключение USB отключает Bluetooth. Поиск устройств сохраняет текущее подключение.

Если в классе несколько контроллеров, выбирайте нужный по адресу Bluetooth, COM-порту и букве диска. Имя модели само по себе не является уникальным идентификатором.

### Bluetooth

1. Закройте RoboCode и другие программы, использующие соединение с контроллером.
2. Включите контроллер и Bluetooth на компьютере.
3. Нажмите «Поиск контроллера по Bluetooth». Пока идёт поиск, панель показывает индикатор выполнения.
4. Нажмите строку своего устройства. Если контроллер запросит разрешение на подключение, подтвердите его на экране.
5. Используйте команды загрузки, Play, Stop и отключения в панели Bluetooth.

**Загрузка** сохраняет Python-файл на контроллере; одноимённый файл заменяется. **Play** выполняет текущий код из редактора, включая несохранённые изменения. **Stop** прерывает программу и выполняет команду остановки контроллера.

### USB

1. Подключите контроллер USB-кабелем. Для загрузки файлов включите на контроллере режим, в котором он отображается как USB-накопитель.
2. Нажмите «Поиск по USB» и выберите нужный контроллер.
3. Если доступен и сопоставлен COM-порт, строка контроллера объединяет диск и порт; выбор строки подключает USB-отладку.
4. Используйте загрузку на накопитель или Play/Stop через COM-порт.

Автоматическое сопоставление накопителя и COM-порта реализовано для Windows. Если сведения Windows недоступны, интерфейсы могут отображаться отдельно. Выбор одного накопителя позволяет загружать файлы; для Play и Stop требуется COM-подключение.

**F6** загружает сохранённый активный Python-файл через выбранный способ подключения. Если файл изменён, расширение сохраняет его перед загрузкой. Для загрузки программы с `gyro_lib` библиотека также копируется на контроллер.

Подробности подключения, передачи и выполнения программы доступны в командах **«Журнал USB»** и **«Журнал Bluetooth»**.

## ИИ-камера E7-RCU

В наборе E7 откройте раздел **«ИИ-камера» → «Руководство и примеры»**. Руководство описывает режимы камеры, параметры команд и чтение результатов. Его также можно открыть отдельно: [руководство по ИИ-камере](docs/AICAM_GUIDE.md).

Доступны режимы `camera`, `face`, `apriltag`, `qrcode`, `detector`, `color`, `road`, `gesture`, `human`, `classifier` и `image`. Название режима передаётся текстом.

Семь примеров помогают проверить связь и поля результата, распознавать обученное лицо, читать QR-коды, находить цвет, получать точки линии и координаты человека, а также ехать по линии с простым ПД-регулятором.

В примере движения по линии используется рабочая схема E7: отрицательная скорость левого мотора, нормированное отклонение `(X - 320) / 6.4` и коэффициенты из ячеек памяти. Порты меняются под свою конструкцию. Настройку линии и обучение объектов выполняйте по руководству камеры.

## Учебные примеры

Обновлены примеры линии по двум датчикам света и старой камере, движения и поворота по энкодерам, синхронизации моторов, Bluetooth-пульта, настройки параметров на экране, работы с экраном и файлами.

Для регуляторов используется единая схема:

| Ячейка | Значение в программе |
| --- | --- |
| 1 | `speed = rcu.GetData(1)` |
| 2 | `kP = rcu.GetData(2) / 10` |
| 3 | `kI = rcu.GetData(3) / 1000` |
| 4 | `kD = rcu.GetData(4)` |

ПД-регулятор не использует И-составляющую. Показания света нормируются по ячейке с номером порта: `sensor.GetLightSensor(port) / rcu.GetData(port)`. В примерах двух датчиков используются порты и ячейки 5/6; значения нормировки должны быть ненулевыми.

Назначение ячеек в других программах указано в комментариях соответствующего примера. Подробнее — в [описании регуляторов](docs/REGULATORS.md).

## Обновление прошивки контроллера

Если на роботе возникает ошибка импорта библиотеки или неизвестной команды, проверьте совместимость программы с моделью и прошивкой контроллера. Используйте прошивку для своей модели из RoboCode или с официального ресурса производителя.

Ниже приведён порядок обновления **E6-RCU через USB** из предыдущей версии инструкции. Для E7-RCU и H-RCU используйте инструкции к соответствующей модели.

1. Скачайте подходящий архив **E6RCU U Disk Upgrade Firmware** с [ресурса производителя](https://www.stemtown.com/resource) и распакуйте его.
2. Включите питание E6-RCU и нажмите «Download» или «Download Program», чтобы перейти в режим загрузки через USB.
3. Подключите контроллер к компьютеру USB-кабелем.
4. Скопируйте `UPDATE.DAT` в корневую папку накопителя контроллера.
5. Выключите и снова включите контроллер, затем дождитесь окончания обновления. Во время обновления питание не выключайте.

Если обычное обновление не удалось, в прежней инструкции предусмотрен режим восстановления: удерживайте левую и правую кнопки при включении питания, подключите USB, скопируйте `UPDATE.DAT` на диск RCU и перезапустите устройство. Сверьте порядок восстановления с инструкцией именно вашей модели и версии прошивки.
