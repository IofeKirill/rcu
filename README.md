# ZMROBO Russian (Not official)

Расширение для программирования роботов ZMROBO в Visual Studio Code. Помогает писать программы на Python, работать с E6 на C создавать программы блоками и проверять алгоритмы в 2D-модели без физического робота.

Это неофициальный проект. Автор не связан с компанией ZMROBO.

## Возможности

- Команды для E6-RCU, E7-RCU и H-RCU с описаниями на русском языке и примерами.
- Вставка команд в программу, автоматическое добавление импортов и настройка портов.
- Загрузка программ по USB и Bluetooth. Запуск и остановка Python-программ с компьютера.
- Программирование E6 на C: команды, примеры, компиляция и загрузка на контроллер.
- 2D-модель с редактором поля, несколькими роботами и заданиями с подсчётом баллов.
- Блочный редактор для E6, M6 и E7 с генерацией Python, подключением USB/Bluetooth и запуском в модели.

## Программа из блоков

В системных командах выберите «Создать программу из блоков» или «Открыть программу из блоков». Проект сохраняется в `.zmblocks`. Выберите E6, M6 или E7, соберите программу и нажмите «Подключить» для USB или Bluetooth. «Загрузить на робота» передаёт программу контроллеру, ▶ запускает её через USB COM или Bluetooth. При подключении только как накопитель файл запускается из меню робота.

Кнопка «Симулятор» передаёт программу в 2D-модель без запуска; выполнение начинается по ▶ в окне модели. Кнопка Python открывает код с подсветкой. Меню «Файл» позволяет экспортировать Python. Тёмная тема включена по умолчанию; ширины панелей настраиваются разделителями, обзор проекта помогает перемещаться по большим программам.

## Первая программа

1. Создайте или откройте папку проекта в VS Code.
2. Откройте панель ZMROBO на боковой панели. В разделе **«Команды для робота»** выберите свой контроллер: E6, E7 или H.
3. В **«Системных командах»** нажмите **«Создать файл для проекта»** и задайте имя программы.
4. Нажмите на нужную команду в списке — она появится в редакторе. Замените параметры своими значениями. Для перехода между полями используйте Tab.
5. Подключите контроллер по USB или Bluetooth, выберите его в соответствующей панели и нажмите **F6** для загрузки.

Новый Python-файл содержит `import rcu` и функцию `task1()`. Импорты остальных библиотек добавляются при вставке команд.

**Описание команды:** правая кнопка мыши → «Информация о команде». **Готовые программы:** «Системные команды» → «Примеры программ». Пример открывается в новом документе; сохраните его перед загрузкой.

Чтобы проверить алгоритм без робота, откройте Python-файл и выберите **«Открыть 2D-модель»** в конце списка системных команд. Порядок запуска описан [ниже](#2d-модель).

## Что нужно для работы

В Windows 10/11 x64 Python и библиотеки для подключения по USB и Bluetooth входят в расширение. Для Bluetooth нужен адаптер с поддержкой BLE. Для запуска и остановки программы по USB нужен COM-порт контроллера.

Для редактирования Python-кода рекомендуются расширения **Python** и **Pylance** от Microsoft. Расширение **indent-rainbow** помогает различать уровни отступов.

В других ОС для подключения используется внешний Python 3.10+ с библиотеками `bleak` и `pyserial`. Путь к нему можно указать в настройке **ZMROBO → Bluetooth: Python Path**. Эта настройка действует и для Bluetooth, и для USB.

Библиотеки робота выполняются на контроллере. Для проверки программы на компьютере используйте 2D-модель с учётом [её ограничений](docs/SIMULATOR.md#ограничения).

## Команды и порты

Выбор E6, E7 или H меняет список команд. Написанная программа при переключении сохраняется. В списке E7 есть отдельный раздел **«ИИ-камера»** с руководством и примерами работы с камерой.

В начале списка находится **«Избранное»**. Добавляйте и удаляйте команды через контекстное меню. Для каждого контроллера, а также для Python и C сохраняются отдельные списки.

Команда **«Настроить порты»** позволяет задать имена моторам и датчикам. Для E6 доступны четыре моторных и восемь датчиковых портов; для остальных наборов — по восемь. Используйте понятные имена, например `LEFT_MOTOR` и `LIGHT_SENSOR`. В Python они записываются в программу как переменные:

```python
LEFT_MOTOR = 1
RIGHT_MOTOR = 3
LIGHT_SENSOR = 5
```

Подставляйте эти имена в команды вместо номеров портов. Настройка портов обновляет назначения в коде; подключать устройства нужно к соответствующим разъёмам контроллера.

## Подключение и загрузка

### USB

1. Подключите контроллер USB-кабелем. Для загрузки файлов переведите его в режим USB-накопителя.
2. В панели **«Устройства USB»** нажмите **«Поиск по USB»** и выберите свой контроллер.
3. Нажмите **F6**, чтобы загрузить активный файл.

Если у контроллера доступен COM-порт, через него можно запускать и останавливать Python-программы кнопками **Play** и **Stop**. Выбранного USB-накопителя достаточно для загрузки файлов.

В Windows расширение сопоставляет накопитель и COM-порт одного контроллера. Если сопоставить их не удалось, они могут отображаться отдельно. При нескольких подключённых роботах проверяйте букву диска и номер COM-порта.

### Bluetooth

1. Включите контроллер и Bluetooth на компьютере. Закройте RoboCode и другие программы, использующие подключение к роботу.
2. В панели **«Bluetooth»** нажмите **«Поиск по Bluetooth»**.
3. Выберите своё устройство. Если контроллер запросит подтверждение, разрешите подключение на его экране.
4. Используйте **F6** для загрузки, **Play** для запуска и **Stop** для остановки Python-программы.

Если рядом несколько контроллеров, сверяйте адрес устройства: имена у них могут совпадать.

### Загрузка и запуск

| Действие | Результат |
| --- | --- |
| F6 или кнопка загрузки | Сохраняет активный Python-файл на контроллере. Перед загрузкой сохраняет изменения в редакторе. Одноимённый файл на роботе заменяется. |
| Play | Выполняет текущий Python-код из редактора, включая несохранённые изменения. |
| Stop | Прерывает Python-программу и отправляет команду остановки контроллера. |

Одновременно используется одно подключение: выбор USB отключает Bluetooth, подключение по Bluetooth отключает USB. Цвет индикатора показывает состояние: красный — не подключено, жёлтый — идёт подключение, зелёный — подключено. У отдельного USB-накопителя зелёный означает, что он выбран для загрузки.

Если подключение или загрузка не удаются, откройте **«Журнал USB»** или **«Журнал Bluetooth»** в соответствующей панели.

## Программирование на C

Режим C доступен для **E6-RCU**. Выберите E6 и нажмите **«Переключиться на C»** в системных командах. Там появятся создание C-файла, настройка портов и **«Примеры C»**. Вернуться к Python можно в том же разделе.

Для первой проверки откройте **«Примеры C» → «Проверка C: текст на экране»**, сохраните файл, выберите контроллер и нажмите **F6**. Расширение скомпилирует программу и загрузит файл `.bin` по USB или Bluetooth. Компилятор ARM GCC и библиотеки E6 входят в Windows-сборку.

Запускайте C-программу из меню контроллера. Кнопки Play и Stop в панелях подключения предназначены для Python.

В C-файле используется заголовок `#include "zmrobo.h"`. Результаты компиляции сохраняются в папке `.zmrobo-build` рядом с исходным файлом. Среди примеров есть управление двумя моторами и движение по линии с ПД-регулятором.

## 2D-модель

Модель позволяет проверять Python-программы на виртуальном поле: следить за движением робота, показаниями датчиков, энкодерами, памятью, переменными и выводом программы.

1. Откройте папку со своей программой и Python-файл. Для запуска папка должна быть доверенной в VS Code.
2. В системных командах выберите **«Открыть 2D-модель»**.
3. Выберите шаблон поля и нажмите **«Загрузить»**.
4. Во вкладке **«Робот»** выберите конструкцию и настройте порты под свою программу.
5. Нажмите **▶** для запуска. Кнопка **■** останавливает программы, **↶** возвращает роботов и предметы на старт.

Доступны датчики света и цвета, ультразвуковой, лазерный и ИК-датчик расстояния, датчик нажатия, линейка из семи элементов, гироскоп и «Умный глаз». Цвета линейки и глаза настраиваются во вкладке «Робот».

Можно рисовать свои трассы, добавлять стены, банки и мячи, устанавливать захват или пиналку. Доступны E6, E7, M6 и автомобиль с рулевым управлением. На одном поле могут работать несколько роботов с отдельными программами.

Во вкладке **«Задание»** нажмите **«Редактировать задание»**. Конструктор позволяет выбрать шаблон, добавить этапы, зоны, предметы, баллы и нарушения. Условия можно проверить вручную, перемещая объекты на поле без программы. Есть готовые задания: кегельринг и «Большое путешествие».

Кнопка **⚑** рядом с запуском включает тренировочный режим: проверки задания, лимит времени и начисление баллов отключаются. При переключении режима текущий запуск останавливается, результат задания сбрасывается. Физика и датчики продолжают работать.

Кнопка **🔒** над полем защищает линии, стены, зоны и фон от случайного редактирования. Роботов и предметы при этом можно перемещать.

Во вкладке **«Показания»** датчики и энкодеры расположены над переменными. Кнопка **«Прочитать показания»** считывает датчики при текущем положении роботов без запуска программы.

Модель поддерживает часть команд `rcu`, `motor`, `sensor` и `trace`, а также библиотеку `gyro_lib`. Программы на C и программы для H-RCU в ней не выполняются; камеры не моделируются. Проверку на настоящем роботе модель не заменяет.
