Загрузка файла на устройство

Команда создаёт копию текущего открытого файла на подключённом устройстве.
Чтобы использовать эту функцию, обнаружте устройство при помощи команды в нижней левой панели и выберите его в качестве активного.
Подсказка: при выполнении команд для работы с устройствами в правом нижнем углу экрана появляются уведомления об успешности операции.

Открыть примеры

Команда открывает страницу с примерами готовых программ, протестированных на роботе. Их можно загрузить на устройство так же, как и собственные программы.

Создать папку проекта

Команда создаёт папку для вашего проекта и инициализирует в ней новый проект.

Создать файл проекта

Команда создаёт файл проекта на языке Python с готовым шаблоном. Для использования должна быть открыта папка проекта.

"no_reversal" - моторы не развёрнуты

Пример:

Датчик цвета

Параметры: порт, режим
Читает показание с датчика цвета в нужном режиме.
Режимы:
1~3: Считать значения RGB (по отдельности).
4: Распознанный цвет (соответствие результата и цвета): 1 — красный, 2 — зелёный, 3 — синий, 4 — жёлтый, 5 — чёрный, 6 — белый
5: Прочитать данные в формате RGB888.
6~8: Прочитать исходные данные RGB.
9~11: Значение имитированного освещения RGB.
12~14: Значения соотношения баланса белого.
15: Оттенок (Hue).
16: Насыщенность (Saturation).
17: Яркость (Brightness).
18: Зарезервировано.
19: Максимальное выходное значение.
20~60: Команды настройки.
61~66: Эталонные значения расширения цвета.
67: Эталонное значение белого.
68: Эталонное значение чёрного.
Значение 999 означает, что данные не считаны или произошла ошибка при считывании.

Пример:


while True:
    if (sensor.GetColorSensor(2, 4) == 2):
        rcu.SetInBeep(1)
# если в режиме цвета виден зелёный, включаем пищалку
    else:
        rcu.SetInBeep(0)
# иначе выключаем пищалку
    rcu.SetWaitForTime(0.001)  
# задержка в цикле

Чтение гироскопа

Параметры: порт, режим, пустой
Чтение показаний гироскопа с выбранной оси.
ВАЖНО! Поворот на 90 градусов - это 900, а не 90.
Режимы:
1 - Крен
2 - Наклон
3 - Рысканье
4 - aX
5 - aY
6 - aZ
7 - gX
8 - gY
9 - gZ

Пример:


sensor.SetAHRS(4, 1)
# сброс показаний перед циклом
while (sensor.GetAHRS(4, 3, 0) < 900):
    motor.SetMotor(1, 50)
    motor.SetMotor(2, -50)
# Пока на гироскопе меньше 90 градусов поворачивай
    rcu.SetWaitForTime(0.001)
# задержка в цикле 
motor.SetMotor(1, 0)
motor.SetMotor(2, 0)
# обязательная остановка после поворота!

Создание объекта для гироскопа

Создаёт объект класса gyro_lib. Вызывает калибровку гироскопа
ВАЖНО! Это не родная библиотека ZMROBO, а созданная мной для увеличения точности прочтения гироскопа.
Для использования библиотеки необходимо в начале программы её вызвать командой import gyro_lib. Тогда система загрузит библиотку в корневую папку Вашего робота.
Команда CalibrateGyro() проводит 100 измерений гироскопа при старте и высчитывает погрешность работы датчика, после чего вносит её во все измерения, за счет чего он работает намного лучше.
Команда ReadGyro() читает угловую скорость гироскопа, вычитает погрешность, после чего преобразует данные в точный угол поворота.

Пример:

import rcu
import gyro_lib
import motor

gyro = gyro_lib.Gyro(1)          # гироскоп на 1-м порту
gyro.CalibrateGyro()          # калибровка

def task1():
    while True:
        angle = gyro.ReadGyro()   # чтение угла
        rcu.SetDisplayString(1, "Angle = " + str(angle), 0xFFE0, 0x0000)
        rcu.SetWaitForTime(0.05)

Пример:


while True:
    if rcu.GetTouchScreen():
        rcu.SetDisplayString(1,str("".join(("X = ",str(rcu.GetTouchScreenX())))),0xFFE0,0x0000)
        rcu.SetDisplayString(2,str("".join(("Y = ",str(rcu.GetTouchScreenY())))),0xFFE0,0x0000)
# Если коснулись экрана, то выводит в первой строке X-координату косания, а во второй Y-координату касания

Очистка экрана

Параметры: цвет
Очищает экран выбранным цветом. Цвет указывается в шестнадцатиричной системе.
В примере показано, как выполнять очистку экрана не на каждой итерации цикла, чтобы избежать излишнего мерцания и сохранить видимость элементов на экране.

Пример:


timeClear = 0
# обнуляем таймер очистки
while True:
    timeClear = timeClear + 1
# прибавляем к таймеру 1
    if (timeClear == 15):
        rcu.SetLCDClear(0x0000)
        timeClear = 0
# если таймер равен 15, то очищаем дисплей и обнуляем таймер

Условие

Выполняет код, если условие истинно.

Пример:


if (x > 0):
    motor.SetMotor(1, 50)
    motor.SetMotor(2, 50)
# если х > 0, то включи моторы

Условие с двумя вариантами действий

Выполняет один блок кода, если условие истинно, и другой блок — если ложное.

Пример:


if (x > 0):
    motor.SetMotor(1, 50)
    motor.SetMotor(2, 50)
else:
    motor.SetMotor(1, 0)
    motor.SetMotor(2, 0)
# если х > 0, то включи моторы, иначе выключи моторы

Несколько условие подряд

Проверяет несколько условий поочерёдно. Выполняет код для первого истинного условия или запускает код в блоке else, если все условия ложны.

Пример:


if (x > 0):
    motor.SetMotor(1, 50)
    motor.SetMotor(2, 50)
elif (x < 0):
    motor.SetMotor(1, -50)
    motor.SetMotor(2, -50)
else:
    motor.SetMotor(1, 0)
    motor.SetMotor(2, 0)
# если х > 0, то включи моторы, если х < 0, то включи моторы назад, иначе выключи моторы

Цикл с условием

Повторяет выполнение кода, пока условие остаётся истинным.

Пример:


while x > 0:
    motor.SetMotor(1, 50)
    motor.SetMotor(2, 50)
    rcu.SetWaitForTime(0.001)
# пока х > 0 двигайся вперед

Создаёт бесконечный цикл, который будет выполняться постоянно.

Пример:


while True:
    motor.SetMotor(1, 50)
    motor.SetMotor(2, 50)
    rcu.SetWaitForTime(0.001)
# двигайся вперед вечно

Итерационный цикл

Цикл, который итерируется по элементам последовательности (например, списка, строки, множества или диапазона) и выполняет заданный блок кода для каждого элемента.
Он автоматически завершает выполнение, когда переберёт все элементы последовательности.
В Python цикл for удобен для перебора любых итерируемых объектов, таких как списки, строки, кортежи, словари и множества.

Пример 1:


numbers = [1, 2, 3, 4]
for num in numbers:
    print(num)
# В этом примере цикл for проходит по каждому элементу списка numbers и выводит его на экран

Пример 2:

for i in range(5):
    print(i)
# Этот цикл выполнится 5 раз, выводя числа от 0 до 4
